# GUIA DEFINITIVO: COMO HOSPEDAR NO INFINITYFREE SEM TELA BRANCA

Este projeto foi refeito em **PHP Puro com armazenamento em arquivo JSON** para resolver exatamente o problema da tela branca do InfinityFree.

---

## 🛑 POR QUE OCORRIA A TELA BRANCA ANTERIORMENTE?
1. O InfinityFree possui um firewall anti-bot (`aes.js` / cookie de teste) e filtros de compressão que corrompiam os pacotes JavaScript gerados por empacotadores (Vite / React / Webpack).
2. O InfinityFree **NÃO roda Node.js**, portanto servidores baseados em Express/Node não funcionam lá.
3. Chunks `.js` externos com caminhos absolutos (`/assets/index.js`) falhavam no carregamento com erro 403 Forbidden ou MIME type incorreto.

---

## ✅ POR QUE ESTA VERSÃO EM PHP PURO FUNCIONA PERFEITAMENTE?
- **Renderização 100% no Servidor (SSR):** O Apache do InfinityFree executa o PHP e entrega o HTML completo e pronto para o navegador.
- **Zero compilação:** Não precisa de `npm install`, nem `npm run build`, nem Node.js.
- **Estilos via CDN Oficial:** Usa Tailwind CSS direto do CDN global, sem carregar arquivos CSS ou JS comprimidos locais que o InfinityFree costuma corromper.
- **Banco de Dados em JSON nativo:** Salva e lê tudo diretamente de `barber_data.json` (no mesmo diretório, **SEM PASTAS**!) através das funções nativas do PHP (`file_get_contents`, `file_put_contents` com `flock`).

---

## 🚀 PASSO A PASSO PARA SUBIR NO INFINITYFREE (SEM PASTAS):

### Passo 1: Acessar a pasta `htdocs`
1. Faça login no painel do InfinityFree (https://dash.infinityfree.com).
2. Clique na sua conta de hospedagem e abra o **Online File Manager** (ou conecte via FileZilla com seus dados de FTP).
3. Entre na pasta **`htdocs`**.
4. **IMPORTANTE:** Se houver arquivos padrão dentro de `htdocs` (como `index2.html` ou arquivos antigos), **apague todos**. A pasta `htdocs` deve estar limpa.

### Passo 2: Enviar os arquivos deste projeto (TODOS NA RAIZ, SEM PASTAS)
Envie todos os arquivos diretamente para dentro de **`htdocs/`** (não crie nenhuma pasta):
- `index.php` (Página principal de agendamento)
- `login.php` (Tela de acesso para Admin, Barbeiros e Clientes)
- `admin.php` (Painel completo de administração)
- `barbeiro.php` (Painel da agenda dos barbeiros)
- `meus-agendamentos.php` (Painel do cliente)
- `db.php` (Conexão e funções do banco JSON)
- `api.php` (Endpoints auxiliares)
- `logout.php` (Encerramento de sessão)
- `barber_data.json` (Base de dados em JSON já preenchida)
- `.htaccess` (Configuração Apache: proteção do JSON e anti-compressão)

*Dica: Você também pode enviar o arquivo `barbearia-php-sem-pastas.zip` e clicar com o botão direito em "Extract" direto no File Manager do InfinityFree! Todos os arquivos vão direto para `htdocs/` sem criar subpastas.*

### Passo 3: Permissões de escrita (CHMOD) se necessário
No gerenciador de arquivos do InfinityFree:
- Clique com o botão direito no arquivo **`barber_data.json`** e em **Permissions / Chmod**.
- Defina permissão **`666`** ou **`777`** (para que o PHP possa gravar os novos agendamentos no arquivo).
*(Nota: Se o arquivo `barber_data.json` for criado pelo próprio PHP, ele já terá permissão automática).*

### Passo 4: Pronto!
Acesse o seu domínio gratuito do InfinityFree (ex: `https://seunome.epizy.com` ou `https://seunome.infinityfreeapp.com`).
O sistema abrirá imediatamente, com agendamentos em tempo real e painéis completos!
